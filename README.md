#  MoodTrack

A simple Flutter mood tracker app that allows users to record their daily mood and view their mood history.

##  Features

* Select your daily mood
* Add a short note
* Save your mood
* View mood history
* Simple and beginner-friendly Flutter UI

## Built With

* Flutter
* Dart

## Screens

### Home

Select how you are feeling today and save your mood.

### History

View previously recorded moods.

##  Getting Started

Clone the repository:


git clone <your-repository-url>


Open the project:


cd mood_tracker


Install dependencies:


flutter pub get

Run the application:


flutter run
